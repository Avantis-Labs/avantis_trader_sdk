## USDC approval

Trading collateral is pulled from your wallet, so USDC must be approved to the protocol once:

```python
await client.account.approve_usdc()          # unlimited, to TradingStorage
await client.account.approve_usdc(5000)      # or a fixed amount
```

```python
info = await client.account.allowance()      # {"balance": ..., "allowance": ...} + human floats
```

<Warning>
Approvals must come from the **trader's own key**; they cannot be routed through a delegate/API key. If you onboarded via the [Avantis API Key Generator](https://delegate.avantisfi.com/), USDC was approved in the same flow and you can skip this.
</Warning>

### LP vault approval is separate

The LP vault pulls from an allowance on the **tranche**, not TradingStorage:

```python
meta = await client.meta()
tranche = meta["addresses"]["tranche"]
await client.account.approve_usdc(1000, spender=tranche)
```

See [LP vault](/more/lp-vault).

## Claims

Both are caller-scoped: the signing key must be the account that earned them (no delegate):

```python
await client.account.claim_rebate()           # referral rebates (you are the referrer)
await client.account.claim_keeper_rewards()   # keeper rewards
```

## Builder codes

Partners routing order flow can register a builder code that collects a per-trade fee — a percent of the trade's collateral or a fixed USDC amount, paid by the trader to your fee collector. Check a code first (`registered: False` means it's free to claim; the response also carries the protocol fee caps):

```python
info = await client.account.builder_code("MYAPP")
# {"registered": False, "owner": None, ..., "maxFeePercentHuman": 1, "maxFixedFeeUsdc": 10}
```

```python
await client.account.register_builder_code(
    "MYAPP",
    fee_collector="0x...",
    is_percent_fee=True,
    fee_percent=0.05,         # 1 = 1% of collateral
)
```

`modify_builder_code(...)` (same parameters, owner only) updates it. Registration is caller-scoped like claims: the caller becomes the code owner, so it cannot go through a delegate key. There's also a no-code flow in the [Avantis API Key Generator](https://delegate.avantisfi.com/).

To attach your code to outgoing orders, set `builder_code` in the [configuration](/configuration) to the normalized 32-byte value (`info["code"]` from the lookup above).
