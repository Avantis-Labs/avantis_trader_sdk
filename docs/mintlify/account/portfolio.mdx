---
title: Portfolio and History
description: "Trade history, PnL analytics, and everything the Veranta portfolio page shows."
---

`client.info` is the read-only analytics surface. Every method takes a trader address, so you can query any account, returns human units, and needs no signing key.

<CodeGroup>

```python Python
trader = client.trade.trader      # or any address

history = await client.info.trade_history(trader, page=0, limit=20)
pnl = await client.info.portfolio_pnl(trader)
```

```typescript TypeScript
const trader = client.trade.trader;  // or any address

const history = await client.info.tradeHistory(trader, 0, 20);
const pnl = await client.info.portfolioPnl(trader);
```

</CodeGroup>

## History

| Python | TypeScript | Returns |
| --- | --- | --- |
| `trade_history(trader, page, limit)` | `tradeHistory(trader, page, limit)` | Fills with the full fee breakdown: gross and net PnL, fees, funding |
| `order_history(trader, page, limit)` | `orderHistory(trader, page, limit)` | Order lifecycle history |
| `recent_trades(pair_index)` | `recentTrades(pairIndex)` | Recent market-wide trades for a pair |

## Portfolio analytics

| Python | TypeScript | Returns |
| --- | --- | --- |
| `portfolio_pnl(trader, grouped=False)` | `portfolioPnl(trader, { grouped })` | Total profit or loss, optionally split by pair group |
| `portfolio_pnl_history(trader, period, date_group)` | `portfolioPnlHistory(trader, period, dateGroup)` | PnL over time |
| `portfolio_volume(trader, grouped=False)` | `portfolioVolume(trader, { grouped })` | Total traded size |
| `win_rate(trader, grouped=False)` | `winRate(trader, { grouped })` | Win-rate statistics |
| `total_fees(trader)` | `totalFees(trader)` | Total fees paid |
| `loss_protection_received(trader)` | `lossProtectionReceived(trader)` | Loss-protection payouts received |
| `portfolio_highlights(trader)` | `portfolioHighlights(trader)` | Best and worst trades |
| `leaderboard(trader=None)` | `leaderboard(trader?)` | The global leaderboard, optionally centered on a trader |

## Referral and vault reads

| Python | TypeScript | Returns |
| --- | --- | --- |
| `referral_stats(trader)` | `referralStats(trader)` | Fees, rebates and referred trader counts, as referrer and as trader |
| `referral_count(trader)`, `referred_fees(trader)` | `referralCount(trader)`, `referredFees(trader)` | Referral counts and fee volumes |
| `vault_returns()`, `vault_share_rate_returns(chart=False)` | `vaultReturns()`, `vaultShareRateReturns({ chart })` | LP vault yield and share-rate returns |
| `user_vault_info(vault_type, trader)` | `userVaultInfo(vaultType, trader)` | A trader's vault position |
| `app_status()` | `appStatus()` | API and app status |

<Note>
Endpoints degrade gracefully. One that is missing on a deployment raises `ApiError` with status 404 instead of breaking the client.
</Note>

For **open** positions and live unrealized PnL, use [positions](/account/positions). `client.info` covers settled history and aggregates.
