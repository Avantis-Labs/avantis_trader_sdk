---
title: LP Vault
description: "Provide USDC liquidity to the Veranta vault and earn from trading fees."
---

The liquidity vault is an ERC-4626 tranche. You deposit USDC and receive vault shares. There is no lock and no epoch: withdrawals are immediate, limited only by how much of the vault is currently in use by open trades.

<Warning>
Vault actions are caller-scoped. The signing key is the LP account, so an API key cannot perform them. Use your wallet key and leave `VERANTA_TRADER_ADDRESS` / `trader` unset.
</Warning>

## One-time approval

The vault pulls USDC from an allowance on the **tranche** contract, not the trading contract:

<CodeGroup>

```python Python
meta = await client.meta()
await client.account.approve_usdc(1000, spender=meta["addresses"]["tranche"])
```

```typescript TypeScript
const meta = await client.meta();
await client.account.approveUsdc(1000, { spender: meta.addresses.tranche as `0x${string}` });
```

</CodeGroup>

## Deposit and withdraw

<CodeGroup>

```python Python
await client.lp.deposit(1000)        # USDC in, shares to you
await client.lp.withdraw(500)        # USDC out, if utilization allows
```

```typescript TypeScript
await client.lp.deposit(1000);       // USDC in, shares to you
await client.lp.withdraw(500);       // USDC out, if utilization allows
```

</CodeGroup>

`mint(shares)` and `redeem(shares)` are the exact-share variants. All four accept a `receiver`, and withdraw and redeem accept an `owner`, for third-party flows.

## Vault state

<CodeGroup>

```python Python
state = await client.lp.state()
# totals, share price, utilization, and your max withdraw and redeem right now
```

```typescript TypeScript
const state = await client.lp.state();
// totals, share price, utilization, and your max withdraw and redeem right now
```

</CodeGroup>

If a withdrawal is larger than the current headroom, read `maxWithdraw` from the state and retry with a smaller amount.

## Yield analytics

Historic returns come from the read-only info API:

<CodeGroup>

```python Python
await client.info.vault_returns()
await client.info.vault_share_rate_returns(chart=True)
await client.info.user_vault_info("junior", trader)
```

```typescript TypeScript
await client.info.vaultReturns();
await client.info.vaultShareRateReturns({ chart: true });
await client.info.userVaultInfo("junior", trader);
```

</CodeGroup>
