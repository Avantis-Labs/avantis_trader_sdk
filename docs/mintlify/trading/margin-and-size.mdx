title: Margin and Position Size
description: "Add or remove collateral, and add size to a position you already have."
---

## Adjust margin

Depositing collateral lowers the effective leverage and moves the liquidation price further away. Withdrawing does the opposite.

<CodeGroup>

```python Python
pos = (await client.account.positions()).positions[0]

await client.trade.update_margin(pos.pair_index, pos.index, "deposit", 50)    # add 50 USDC
await client.trade.update_margin(pos.pair_index, pos.index, "withdraw", 25)   # remove 25 USDC
```

```typescript TypeScript
const pos = (await client.account.positions()).positions[0];

await client.trade.updateMargin(pos.pairIndex, pos.index, "deposit", 50);     // add 50 USDC
await client.trade.updateMargin(pos.pairIndex, pos.index, "withdraw", 25);    // remove 25 USDC
```

</CodeGroup>

Preview the effect first with the liquidation estimate in [Compute](/data/compute#liquidation-price). Margin updates execute against a fresh oracle price, which the SDK attaches for you.

## Increase position size

Adds collateral at a leverage of your choice. The position's average open price is re-weighted on-chain.

<CodeGroup>

```python Python
await client.trade.increase_position(
    pos.pair_index, pos.index,
    collateral=100,          # additional USDC
    leverage=10,             # applied to the added collateral only
    slippage_percent=1,
)
```

```typescript TypeScript
await client.trade.increasePosition(pos.pairIndex, pos.index, {
  collateral: 100,         // additional USDC
  leverage: 10,            // applied to the added collateral only
  slippagePercent: 1,
});
```

</CodeGroup>

| Python | TypeScript | Default | Meaning |
| --- | --- | --- | --- |
| `collateral` | `collateral` | required | Additional USDC |
| `leverage` | `leverage` | required | Leverage for the added collateral, not for the whole position |
| `open_price` | `openPrice` | live price | Reference price for the fill |
| `slippage_percent` | `slippagePercent` | `1` | Maximum slippage on the increase |
| `on_event` | `onEvent` | none | Lifecycle hook, like market orders |

Increases route through the batched-market service like market orders, so the receipt is fill-aware and ends with a `PositionSizeIncreased` event.

## Increase sized in coin units

Targets extra coin exposure. All three leverage arguments are required here.

<CodeGroup>

```python Python
await client.trade.increase_position_coin(
    pos.pair_index, pos.index,
    collateral=100,
    coin_exposure=0.25,      # ETH to add
    leverage=10,             # reference leverage
    min_leverage=5, max_leverage=20,
)
```

```typescript TypeScript
await client.trade.increasePositionCoin(pos.pairIndex, pos.index, {
  collateral: 100,
  coinExposure: 0.25,      // ETH to add
  leverage: 10,            // reference leverage
  minLeverage: 5, maxLeverage: 20,
});
```

</CodeGroup>

<Note>
To **reduce** size, close part of the position with a partial [market close](/trading/market-orders#close-a-position). There is no separate decrease method.
</Note>
