Both SDKs read their settings in the same order: **constructor arguments win over environment variables, which win over the network defaults**. Most people set two environment variables and nothing else.

```bash
export VERANTA_PRIVATE_KEY=0x...      # signing key (an API key, or your wallet key)
export VERANTA_TRADER_ADDRESS=0x...   # your wallet, only when the key above is an API key
```

## Environment variables

| Variable | Default | What it does |
| --- | --- | --- |
| `VERANTA_PRIVATE_KEY` | none | The signing key. Use an API key from the [Veranta API Key Generator](https://delegate.veranta.xyz/), or your wallet key. |
| `VERANTA_TRADER_ADDRESS` | none | The wallet that holds the USDC and the positions. Set it only when the key above is an API key. |
| `VERANTA_NETWORK` | `mainnet` | `mainnet` or `testnet`. |
| `VERANTA_EXECUTION` | `relayer` | `relayer` is gasless. `direct` broadcasts through your own RPC. See [Execution modes](/advanced/execution-modes). |
| `VERANTA_RPC_URL` | none on mainnet, the fork RPC on testnet | A Base RPC. Required for `direct` execution. In relayer mode it is only needed when you sign with your wallet key instead of an API key. |
| `VERANTA_BUILDER_CODE` | none | Attribute your order flow to a builder code. See [Builder codes](/builders/builder-codes). |
| `VERANTA_BUILDER_FEE_PERCENT` | none | Default per-order builder fee, as a percent of notional. |
| `VERANTA_API_BASE_URL` | per network | The gateway every routed service derives from. |

The routed services (core, TWAP, batched market, relayer, data, risk engine) all derive from one base URL: `https://prod-api.veranta.xyz` on mainnet and `https://staging-api.veranta.xyz` on testnet. You rarely need the per-service overrides, but they exist and win over the derivation: `VERANTA_TX_BUILDER_URL`, `VERANTA_RELAYER_URL`, `VERANTA_CORE_API_URL`, `VERANTA_TWAP_API_URL`, `VERANTA_BATCHED_MARKET_URL`, `VERANTA_DATA_API_URL`, `VERANTA_RISK_V2_API_URL`, `VERANTA_HISTORY_API_URL`, `VERANTA_FEED_URL`.

<Note>
Coming from Avantis? The old `AVANTIS_*` names still work when the `VERANTA_*` one is not set. The SDK prints a deprecation warning so you remember to rename them. Details in [Avantis is now Veranta](/migration/rename).
</Note>

## Constructor options

Anything the environment can set, the constructor can override.

<CodeGroup>

```python Python
from veranta_sdk import AsyncVeranta

client = AsyncVeranta(
    private_key="0x...",
    trader_address="0x...",
    network="mainnet",
    execution="relayer",             # or "direct"
    rpc_url="https://mainnet.base.org",
    timeout_s=30,                    # HTTP timeout
    relay_poll_timeout_s=60,         # how long wait=True follows an order
    builder_code="MYAPP",            # optional, see Builder codes
    builder_fee_percent=0.05,
)
```

```typescript TypeScript
import { Veranta } from "veranta-sdk";

const client = new Veranta({
  privateKey: "0x...",
  trader: "0x...",
  network: "mainnet",
  execution: "relayer",             // or "direct"
  rpcUrl: "https://mainnet.base.org",
  timeoutMs: 30_000,                // HTTP timeout
  relayPollTimeoutMs: 60_000,       // how long wait: true follows an order
  builderCode: "MYAPP",             // optional, see Builder codes
  builderFeePercent: 0.05,
});
```

</CodeGroup>

The TypeScript client also takes a `signer` option instead of `privateKey`: a viem `LocalAccount`, a browser `WalletClient` from wagmi, an AWS KMS signer, or your own signer implementation. The Python client takes a `signer` option for the same purpose. Both are covered in [Signers](/advanced/signers).

## Networks

| | Mainnet | Testnet |
| --- | --- | --- |
| Chain | Base (8453) | A fork of Base with the same chain id and contracts |
| Gateway | `https://prod-api.veranta.xyz` | `https://staging-api.veranta.xyz` |
| tx-builder | `https://tx-builder.veranta.xyz` | `https://tx-builder-testnet.veranta.xyz` |
| Default RPC | none (not needed with an API key) | `https://base-testnet-rpc-ovh.avantisfi.com` |
| Test funds | n/a | `fundTestnetWallet(address)` in the TypeScript SDK |

The testnet RPC and its explorer (`base-testnet-ovh.avantisfi.com`) stay on the `avantisfi.com` domain for now. Every other service has moved to `veranta.xyz`.

## Sync client (Python only)

The Python SDK is async first. `Veranta` is a blocking facade with the same namespaces and methods, handy for notebooks and simple scripts:

```python
from veranta_sdk import Veranta

client = Veranta()
client.trade.market_open("ETH/USD", "long", collateral=100, leverage=10)
client.close()
```

The TypeScript SDK is promise based everywhere, so there is nothing to choose.
