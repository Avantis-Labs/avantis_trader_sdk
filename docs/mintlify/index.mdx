Veranta is a decentralized perpetuals exchange on Base. You trade crypto, forex and commodity pairs with leverage, using USDC as collateral, and every trade settles on-chain.

This site documents the two official SDKs. They have the same features and the same method names, spelled the way each language expects (`market_open` in Python, `marketOpen` in TypeScript). Code samples show both languages side by side.

| | Python | TypeScript |
| --- | --- | --- |
| Install | `pip install veranta-sdk` | `npm i veranta-sdk viem` |
| Import | `from veranta_sdk import AsyncVeranta` | `import { Veranta } from "veranta-sdk"` |
| Runs in | Python 3.10 or newer | Node 20 or newer, browsers, edge runtimes |
| Extras | AWS KMS signing, Socket.IO streams | React hooks at `veranta-sdk/react`, AWS KMS at `veranta-sdk/kms` |

## How trading works

1. **You hold an API key.** It is a separate key registered to your wallet with one signature. It can trade for you, but it can never move your funds.
2. **The SDK builds and signs the order locally.** Your private key never leaves your machine.
3. **The Veranta relayer puts the order on-chain** and pays the gas. You need no ETH, no node, and no contract ABIs.
4. **You get a receipt when the order fills**, not just when the transaction is sent.

Your first trade is a few lines:

<CodeGroup>

```python Python
import asyncio
from veranta_sdk import AsyncVeranta

async def main():
    async with AsyncVeranta() as client:   # reads VERANTA_PRIVATE_KEY and VERANTA_TRADER_ADDRESS
        receipt = await client.trade.market_open("ETH/USD", "long", collateral=100, leverage=10)
        print("filled in tx", receipt.tx_hash)

asyncio.run(main())
```

```typescript TypeScript
import { Veranta } from "veranta-sdk";

const client = new Veranta(); // reads VERANTA_PRIVATE_KEY and VERANTA_TRADER_ADDRESS
const receipt = await client.trade.marketOpen("ETH/USD", "long", { collateral: 100, leverage: 10 });
console.log("filled in tx", receipt.txHash);
```

## Why teams use the SDKs

- **Everything the Veranta app knows, in one client.** Pairs, funding, spreads, open interest caps, positions with liquidation prices, PnL breakdowns, portfolio analytics, referral stats and vault yields.
- **Correct by construction.** Every signed order is checked locally against the hash the API reports before it is signed. The signing code is tested against vectors produced by the on-chain hashing library itself.
- **Built for every kind of user.** One-line market orders for scripts and agents. TWAP, coin-sized orders, self-broadcasting and local signing for institutions. React hooks for frontends.
